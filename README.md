Цель: Познакомиться с синтаксисом JS, базовыми конструкциями и логикой.

Задание:
Добавить на страницу скрипт (script.js), который реализует:
- Ввод/вывод: prompt (имя), alert (приветствие), console.log.
- Условные конструкции и циклы.
- Функции для поиска максимума, фильтрации и подсчёта суммы в массиве

Вариант 15. Тема «Учёный и исследователь» (значения эксперимента) Данные:
массив из 5–7 чисел – результаты измерений в эксперименте (любые единицы). Логика:
фильтрация – значения > среднего. Цикл – аномально низкие значения (≤ 10% от
максимума) и их количество. Функции: максимум, фильтрация, сумма. Вывод: alert –
«Среднее значение – X, Y измерений – выше среднего». Console – количество аномально
низких значений. Доп.: если разброс (max − min) > 50, консоль – «Наблюдается высокая
вариативность данных».
